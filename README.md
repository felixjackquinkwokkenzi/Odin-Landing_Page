# Landing Page - The Odin Project

Welcome to my Landing Page project! This is a simple, responsive webpage built as part of [The Odin Project's Foundations Curriculum](https://www.theodinproject.com).

[Live Demo](https://felixjackquinkwokkenzi.github.io/Odin-Landing_Page/)

## 🚀 About This Project

As a beginner in web development, this project represents a significant milestone in my learning journey. It demonstrates my current understanding of HTML semantic structures and CSS styling techniques. My main focus for this project was mastering **Flexbox** to create clean and organized layouts without relying on external frameworks.

While it's a relatively straightforward layout, it reflects my current skill level and everything I've learned up to this point. I'm excited to keep learning and building more complex projects!

## ✨ Features and Sections

The webpage is divided into five main sections:

- **Hero Section**: A bold introductory area featuring a main headline, subtext, a sign-up button, and an eye-catching image.
- **Information Section**: A cleanly aligned row of four cards (images and text) to showcase features, utilizing Flexbox for perfect spacing.
- **Quote Section**: A prominent area with a contrasting background dedicated to an inspiring quote or testimonial.
- **Call to Action (CTA)**: A distinct, floating box with subtle shadows encouraging users to take action.
- **Footer**: A minimal footer to complete the page structure.

## 🛠️ Built With

- **HTML5**: Utilizing semantic tags (`<header>`, `<section>`, `<footer>`) for better structure and accessibility.
- **CSS3**:
  - Extensive use of **Flexbox** for aligning and distributing space among items.
  - Box Model principles (`margin`, `padding`, borders).
  - Basic responsive design techniques (like `max-width` and `auto` margins).
  - Custom typography styling with Google Fonts (Roboto).

## 💡 What I Learned

Throughout this project, I gained hands-on experience with:

- Centering elements both vertically and horizontally.
- Using `object-fit: cover` to make images scale correctly within their containers without distortion.
- Creating a consistent visual hierarchy using font sizes, weights, and contrasting colors.
- Structuring CSS files logically to keep styles organized.
